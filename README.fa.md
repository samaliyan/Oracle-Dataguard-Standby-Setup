# راه‌اندازی خودکار استندبای فیزیکی دیتا گارد اوراکل

این برنامه یک اسکریپت بش است.
این اسکریپت روی یک سرور جدید، مرحله به مرحله، یک استندبای فیزیکی از دیتابیس اصلی می‌سازد.
اسکریپت روی سرور استندبای اجرا می‌شود.
دیتابیس با روش کپی مستقیم ریمن منتقل می‌شود.

**این اسکریپت هیچ تغییری روی سرور اصلی نمی‌دهد.**
روی سرور اصلی فقط چند بررسی ثابت و فقط‌خواندنی اجرا می‌شود.
هر کاری که لازم است روی سرور اصلی انجام شود، همراه با دستور برگرداندنش چاپ می‌شود.
بعد از اینکه ادمین آن را اجرا کرد، اسکریپت نتیجه را دوباره به‌صورت فقط‌خواندنی بررسی می‌کند.

## پشتیبانی

1. نسخه‌های اوراکل از ۱۲.۱ تا ۲۳ (نسخه‌های جدیدتر پذیرفته نمی‌شوند)
2. اوراکل لینوکس نسخه‌های ۷ و ۸ و ۹ روی سرور استندبای
3. ذخیره‌سازی روی ای‌اس‌ام، روی فایل‌سیستم، یا هر دو
4. گرید با کاربر جداگانه یا با همان کاربر اوراکل

## شروع کار

اسکریپت را روی سرور استندبای کپی کنید و با کاربر روت اجرا کنید.

اول فقط بررسی، بدون هیچ تغییری:

```bash
./dg_standby_setup.sh --check
```

در اولین اتصال، اسکریپت اثر انگشت کلید اس‌اس‌اچ سرور اصلی را نشان می‌دهد.
پیش از تأیید، آن را با خروجی این دستور روی سرور اصلی، با کاربر روت، مقایسه کنید:

```bash
for f in /etc/ssh/ssh_host_*_key.pub; do ssh-keygen -lf "$f"; done
```

اگر یکی نبودند، تأیید نکنید و اول علت را پیدا کنید.

ساختن استندبای:

```bash
./dg_standby_setup.sh
```

اگر اسکریپت بدون هیچ گزینه‌ای اجرا شود، اول یک منو نشان می‌دهد.
در منو می‌توانید کل کار را انتخاب کنید، یا فقط یک بخش را.
برای نمونه فقط آماده‌سازی سیستم‌عامل، فقط نصب گرید، فقط نصب نرم‌افزار دیتابیس، یا چند مرحله‌ی دلخواه.
اسکریپت بعد از آخرین مرحله‌ی آن بخش متوقف می‌شود.

```
   1) Full setup, all phases
   2) OS preparation only                  phase 2
   3) Grid Infrastructure and ASM only     3.1 - 3.5
   4) Database software only               3.6 - 3.11
   5) Primary changes for the DBA          phase 4
   6) Choose steps                         e.g. 2.1-2.4
   7) Health check (daily)                 phase 10
   8) Status, changes and undo
```

همین بخش‌ها از خط فرمان هم اجرا می‌شوند:

```bash
./dg_standby_setup.sh --only os
./dg_standby_setup.sh --only grid
./dg_standby_setup.sh --only db
./dg_standby_setup.sh --only 2.1-2.4
```

پیش از هر مرحله، اسکریپت نشان می‌دهد چه چیزی پیدا کرده و چه کاری می‌خواهد بکند. بعد با این گزینه‌ها از شما می‌پرسد:

```
[y] Yes, do it   [s] Skip   [h] Help   [q] Quit
```

## فرمان‌های مفید

اجرای کارهای همین سرور بدون پرسیدن تک‌تک آن‌ها. این موارد همچنان پرسیده می‌شوند: پاک‌کردن دیسک، کپی دیتابیس، کلید سرور اصلی، رمزها، راه‌اندازی دوباره‌ی listener، مرحله‌هایی که استندبای را دوباره راه می‌اندازند، و تنظیم پاک‌شدن archived log ها:

```bash
./dg_standby_setup.sh --yes
```

دیدن وضعیت همه‌ی مراحل:

```bash
./dg_standby_setup.sh --status
```

دیدن همه‌ی تغییرهایی که اسکریپت روی این سرور داده است:

```bash
./dg_standby_setup.sh --show-changes
```

برگرداندن تغییرهای یک مرحله، مثلاً مرحله‌ی ۵.۱:

```bash
./dg_standby_setup.sh --undo 5.1
```

انجام کارهای سرور اصلی پیش از بقیه، برای اینکه همه در یک زمان تعمیرات انجام شوند:

```bash
./dg_standby_setup.sh --only 4
```

## تست‌ها

بیش از ۴۹۰ سناریو روی محیط شبیه‌سازی‌شده تست شده است.
تست‌ها به کاربر روت نیاز دارند و فایل میزبان‌های سیستم را تغییر می‌دهند.
برای همین فقط باید داخل یک کانتینر یا ماشین مجازی یک‌بارمصرف اجرا شوند، هرگز روی سرور واقعی.

محیط شبیه‌سازی‌شده اوراکل واقعی نیست.
پیش از استفاده روی محیط عملیاتی، حتماً اسکریپت را روی سرورهای واقعی در حالت بررسی اجرا کنید و گزارشش را بخوانید.

## مسئولیت

این برنامه همان‌طور که هست ارائه می‌شود و هیچ ضمانتی ندارد.
اول آن را در محیط غیرعملیاتی آزمایش کنید و از دیتابیس اصلی نسخه‌ی پشتیبان معتبر داشته باشید.
